# 📊 Análise de Acidentes Rodoviários - Sul e Sudeste

## 📌 Visão Geral
Projeto Acadêmico, este projeto consiste em um painel interativo desenvolvido no Power BI Desktop para analisar as ocorrências de acidentes de trânsito nas regiões Sul e Sudeste do Brasil, permitindo a exploração de métricas de gravidade, tipos de acidentes e localização geográfica.

## 🛠️ Tecnologias e Funcionalidades Utilizadas
* **Power BI Desktop:** Construção do modelo de dados e relatórios interativos.
* **DAX:** Criação de colunas calculadas e métricas personalizadas para agregação de dados.
* **Análise Visual:** Utilização de cartões de indicadores, matrizes detalhadas, gráficos de distribuição e mapeamento geográfico.
